# 搬瓦工 VPS 选购与上手指南

BandwagonHost（搬瓦工）提供 VPS 服务：购买后，用户可以通过控制面板管理一台虚拟服务器，再使用 SSH 登录系统，学习 Linux、搭建网站或部署应用。它并不是开通即用的网站程序；系统环境、数据和应用仍需要自己管理。

对于第一次购买的人，值得先回答四个问题：服务器要运行什么，访问者主要在哪里，预计需要多少内存和流量，以及能接受怎样的付款周期。下面从套餐比较讲到注册、连接和维护，帮助你把这些问题落实到具体操作。

## 进入搬瓦工控制面板并连接

账户中心与服务器系统是两个不同的入口。登录账户后，依次进入 **Services → My Services**，找到所购 VPS，点击 **KiwiVM Control Panel**。KiwiVM 可用于开关机、重装系统、查看流量、快照和迁移机房等管理操作；具体可用功能应以所购服务的面板为准。

### 找到连接信息

在 KiwiVM 主页面查看 **IP Address** 和 **SSH Port**。参考资料指出 SSH 端口随机生成，因此不要直接假设是 22。连接前把 IP 和端口分别记录清楚，尤其注意不要把账户密码、服务器密码和端口混为一谈。

如需重置 root 密码，可在左侧菜单找到 **Root password modification**，按面板提示先关闭 VPS，再生成新密码。参考资料提示新密码只显示一次，应立即妥善保存。完成后确认服务器已启动，再尝试连接；密码不应贴在公开文档或聊天记录中。

macOS 可使用自带终端；Windows 可使用 PowerShell、PuTTY 等工具。命令行连接格式如下，将示例变量替换为面板中显示的实际值：

```sh
ssh root@<服务器IP> -p <SSH端口>
```

输入密码时终端通常不会显示字符，这是正常的输入方式。成功登录后即可操作服务器系统；执行不熟悉的管理命令前，应先确认命令的作用和影响范围。

如果本地连接失败，先检查服务器是否开机、IP 和端口是否抄对，再排查本地网络。KiwiVM 中的 **Root shell - interactive** 可作为浏览器内的应急访问方式，用于连接或检查系统；它与本地 SSH 是不同的入口，不应把一次连接失败直接归因于某个单一原因。

## 首次使用与日常维护

### 根据用途准备系统和环境

学习 Linux 时，可以从系统登录、文件管理和基本维护开始，先熟悉面板的开关机与重装入口，再逐步操作。建站除了服务器本身，还需要考虑网站程序、数据库、域名和证书等环节；参考资料提到宝塔面板和 LNMP 环境，但安装前应核对所选系统及资源是否符合工具要求。

部署容器或其他应用时，先查看应用文档中的内存、存储和系统要求，再与套餐配置比较，并为系统运行和数据增长留出空间。参考资料提到 Debian、Ubuntu 等发行版；选择时应同时考虑应用兼容性和系统维护状态。不要仅凭套餐名称推断某个应用一定可以运行。

### 备份、重装与流量

重装系统会清除原有数据。操作前先识别需要保留的网站文件、数据库和配置，建立备份并确认恢复方式；重要数据最好保留在服务器之外，避免把同一台机器上的副本当成唯一保障。KiwiVM 提供快照和 **Backups** 入口，可以在操作前检查可用备份与其时间，再决定是否继续。备份完成后也要考虑如何验证和恢复，而不是只确认创建按钮已经点击。

在面板中定期查看流量统计，将实际用量与套餐月流量对照。若用量增长，先找出产生传输的应用或任务，再评估是否需要调整方案。站点迁移、大文件传输等操作也应计入计划，避免只按平时的访问量估算。

### 迁移前先测试和备份

参考资料给出的 CN2 GIA-E 迁移入口是 KiwiVM 左侧的 **Migrate to different datacenter**。操作前先确认目标机房在当前服务中可选，使用测试 IP 比较实际网络表现，并备份重要数据、确认恢复方法。随后在面板选择目标并核对提示，再决定是否提交迁移。

迁移涉及服务位置变化，应为业务安排合适的操作时间，并在完成后检查连接与应用状态。不同机房的可用性和网络表现可能变化，不应把历史测试结果或迁移耗时当成保证。

## 常见问题

**SSH 端口找不到，或连接不上怎么办？** 先到 KiwiVM 主页面查看 SSH Port 与 IP Address，确认 VPS 已启动，并在连接命令中使用该端口。仍有问题时，可尝试面板内的 Root shell - interactive 进行应急检查。

**需要更换 IP 怎么办？** 参考资料提到可在 KiwiVM 付费更换，费用为每次 $8；SLA 套餐则提到每两周可免费更换一次。费用、适用条件及当前可用操作请以面板和服务条款为准。更换前也应考虑依赖原 IP 的配置，并在变更后检查连接。

**重装前有快照就可以放心清空吗？** 先确认快照或其他备份包含所需数据，并弄清恢复步骤。参考资料提到可在 Backups 中查看自动备份，但不能仅凭备份功能存在就假设某次数据已经可恢复。

**只想练手，是否需要选择高价线路？** 不一定。先看学习任务所需资源和预算；Basic 的示例配置可作为入门比较对象。若有明确的访问地区、线路或服务等级要求，再将 CN2 GIA-E、香港、日本或 SLA 方案纳入选择。

最终下单前，可再次进入[官方套餐列表](https://bwh81.net/aff.php?aff=59244)，对照方案名称、机房、付款周期和价格，确认订单与自己的需求一致。
